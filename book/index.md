# Welcome to Gleebook

**Gleebook** is a modern, ultra-fast static site generator written in **Gleam**. 

It is designed to provide **documentation sites** with an **effortless** local development experience and **zero-config** deployment.

![Gleam and the value of small | Ubuntu Summit 26.04](https://www.youtube.com/watch?v=E6_JqYMeNqs)

## Features

- **Type-Safe Static Site Generation:** Built entirely in Gleam.
- **Instant Watcher & Live Reload:** Automatic rebuilds and browser updates while you write.
- **Collapsible Accordion Sidebar:** Multi-level depth support using native HTML5 components.
- **Dual Theme Engine:** Toggle between **Cyberpunk Pink** and **Rust Olive** out of the box.
