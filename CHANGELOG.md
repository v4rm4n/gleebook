## [0.2.0] - 2026-09-22
### Added
- Native HTML5 video embeds for `.mp4`, `.webm`, and `.ogg` files.
- High-contrast forest green accent color for the `olive` theme.

### Fixed
- Firefox bounding-box rendering artifacts on glowing SVG elements.
- Text overflow wrapping for exceptionally long book titles in the sidebar.
- Dirty text selection cursors appearing on mobile UI elements.
